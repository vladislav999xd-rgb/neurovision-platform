# Электронная регистратура

Учебный проект по Python и медицинской кибернетике. Реализованы задания четырёх
дней: базовая очередь, перенос талона, история с сохранением и возвращение
отменённого талона.

## Возможности

- регистрация, вызов, завершение и отмена талонов;
- фильтры по кабинету, статусу и коду посетителя;
- перенос ожидающего талона в другой кабинет;
- возвращение отменённого талона в конец очереди;
- история успешных действий;
- сохранение и восстановление JSON;
- выгрузка рабочего документа;
- современный адаптивный медицинский интерфейс;
- фоновая аудиодорожка и звук кнопок.

## Запуск

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py --server.port 8501
```

Открыть `http://127.0.0.1:8501`.
