# Современная электронная регистратура

Это отдельная дизайнерская копия учебного проекта. Основная папка `team_1` не изменяется.

## Что находится в копии

- `app.py` — интерфейс Streamlit в стиле современного медицинского dashboard.
- `student_logic.py` — логика дней 1–4: очередь, перенос, журнал и возврат отменённого талона.
- `history_tools.py` — добавление событий и поиск истории талона.
- `io_adapter.py` — сохранение, восстановление и выгрузка документа.
- `assets/clinic_hero.png` — локальный hero-фон современной клиники.
- `assets/quack.mp3` — присланный звук нажатия кнопок.
- `assets/ambient-loop.mp3` — постоянная зацикленная фоновая дорожка.
- `qa/check_cyberpunk.py` — автоматическая проверка интерфейса и звуков (старое имя файла сохранено для совместимости).
- `qa/capture_preview.py` — создание контрольного снимка страницы.
- `check_day4.py` — восемь обязательных проверок возврата в очередь.
- `check_app_day4.py` — проверка кнопки дня 4 и звука всех кнопок.
- `ДЕНЬ_4_ОТВЕТЫ_ПРЕПОДАВАТЕЛЮ.md` — подробное объяснение для защиты.
- `ДЕНЬ_4_ЛИЧНЫЙ_РАЗБОР.md` — готовый индивидуальный разбор.
- `Защита_день_4/Общая_защита_команды_день_4.pptx` — единая презентация для всей команды.

## Запуск

```powershell
cd C:\Users\Vlad\Desktop\URFU\project\registratura_modern
python -m streamlit run app.py --server.port 8501
```

Открыть в браузере: `http://127.0.0.1:8501`.

## Проверки

```powershell
python check_day1.py
python check_homework.py
python check_day2.py
python check_day3.py
python check_day4.py
python check_app_day4.py
```

Фоновая дорожка создаётся с `autoplay=True` и `loop=True`. Браузер может разрешить звук только после первого взаимодействия со страницей — это встроенная политика браузеров. После первого нажатия дорожка продолжает играть по кругу. Для кряканья каждый клик получает уникальный аудиоисточник, поэтому повторные нажатия работают без обновления вкладки.
