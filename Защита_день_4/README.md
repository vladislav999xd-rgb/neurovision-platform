# Защита четвёртого дня

В папке находится одна общая презентация:

- `Общая_защита_команды_день_4.pptx` — 9 слайдов, формат 16:9.
- `Общая_защита_по_дням.pdf` — актуальная защита: 12 слайдов и 4 карточки речи.
- `СЦЕНАРИЙ_ОБЩЕЙ_ЗАЩИТЫ.md` — точная речь, демонстрация и ответы каждому.
- `create_presentations.py` — повторное создание презентации после правок.

Презентация построена по лекции четвёртого дня:

- 8 минут командной демонстрации;
- пользователь и задача;
- основной рабочий путь;
- новое правило и отказ без изменения данных;
- ключевая функция;
- ограничение и итог;
- затем 5 минут вопросов о личном понимании.

Актуальное распределение внутри PDF:

- Алёна — первый день;
- Влад — второй день;
- Хеда — третий день;
- Ира — четвёртый день.

Для повторной генерации:

```powershell
python create_presentations.py
python create_defense_pdf.py
```
