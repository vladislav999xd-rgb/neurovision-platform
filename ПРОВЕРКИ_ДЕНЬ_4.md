# Проверки четвёртого дня

Запускать из папки `registratura_modern`:

```powershell
python check_day1.py
python check_homework.py
python check_day2.py
python check_day3.py
python check_day4.py
python check_app_day4.py
```

Ожидаемый итог каждой команды — сообщение, что все проверки соответствующего
дня пройдены.

`check_day4.py` проверяет восемь обязательных сценариев функции. Отказные ветки
сравнивают весь `state` с глубокой копией. `check_app_day4.py` нажимает новую
кнопку дважды, проверяет одно событие `requeue`, неизменность данных после
повторного отказа, стабильный фоновый звук и новое кряканье для каждой из
двенадцати кнопок.

Запуск сайта:

```powershell
python -m streamlit run app.py --server.port 8501
```

Адрес: `http://127.0.0.1:8501`.
